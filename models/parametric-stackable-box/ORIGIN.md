# Origin

- Forked from: https://github.com/likeablob/parametric-stackable-box
- Original author: likeablob
- Upstream license: MIT (see LICENSE)
- This folder: Customizer comments, listing text, named presets, extra Models, and vendored `scad-utils`. Each Model is a complete article (organizers split with `part`). Box hull and lip are upstream. Battery, grid, hex-bit, and SD inserts live here: they expose the same `body_x` / `body_y` / `body_z` / `wall` as the empty box so the insert stays a fit, and they pack only full pockets.
- Libraries: Oskar Linde scad-utils (vendored `scad-utils/`, MIT). Site preview uses the copy in this folder.
